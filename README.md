# LinkedIn Job Trend Analysis

## Objective
Analyze job skill demand across cities and job roles using Python and Pandas.

## Important note
This project uses a sample dataset for demonstration. Use only publicly available data collected with permission, authorized APIs, or datasets whose terms allow analysis. Do not bypass LinkedIn restrictions, authentication, CAPTCHAs, or access controls.

## Tools
- Python
- Pandas
- Matplotlib
- Excel

## Installation
```bash
pip install pandas matplotlib
```

## Run
```bash
python analyze_jobs.py
```

## Deliverables
The `outputs` folder contains:
- cleaned_skill_data.csv
- top_10_skills.csv
- top_10_skills.png
- skill_city_heatmap.png
- skill_role_matrix.png
- skill_vs_city_matrix.csv
- skill_vs_role_matrix.csv
- role_demand.csv
- city_demand.csv
- job_demand_recommendation.txt

## Excel
Open the generated CSV files in Excel to create PivotTables, charts, and conditional-formatting heatmaps.

## Suggested conclusion
Use the results to identify frequently requested skills and compare demand by city and role. Because the sample dataset is illustrative, conclusions should not be presented as actual LinkedIn market statistics.
